# MVP 솔루션 뽑기 — 슬기로운 단약생활

2026-10-28 · 출발 = 3주차 PRFAQ 「슬기로운 단약생활」(2026-10-25)
목표: PRFAQ에서 6주 MVP에 들어갈 기능만 남긴다.

---

## 시연 ① · PRFAQ 뜯기

### PR에서 「해 준다」는 문장에만 밑줄 → 후보 7개

| 후보 | PR 원문 |
|---|---|
| **A · 비슷한 사례 찾기** | "내 약과 마지막 용량, 맞은 기간, 끊으려는 방식을 넣으면, 같은 조건으로 끊었던 사람들이 그 뒤 몇 달 동안 어떻게 지냈는지를 바로 보여 준다" |
| **B · 시점별 같은 칸 정리** | "같은 조건으로 끊은 사람들의 경험이 「끊은 직후, 1개월, 3개월, 6개월」 순서로 같은 칸에 정리되어 나온다" |
| **C · 고비 시점 N건 중 M건** | "비슷한 사람들이 고비를 겪은 시점 … 도 몇 명이 그렇게 말했는지와 함께 표시된다" |
| **D · 내 타임라인 겹쳐 보기** | "끊은 날을 넣으면 … 내 타임라인 위에 먼저 끊은 사람들의 기록을 겹쳐 지금 내가 어디쯤인지 보여 준다" |
| **E · 조건 넓히기** | "딱 맞는 사례가 없으면 조건을 하나씩 넓혀 가장 가까운 사례를 보여 주고, 무엇을 넓혔는지를 함께 적는다" |
| **F · 경험 남기기** | "검색이 끝나면 「당신의 경험이 다음 사람의 사례가 됩니다」라며 내 단약 기록을 남기도록 이어 주고" |
| **G · 1·3·6개월 재질문** | "다시 연락해도 된다고 동의한 사람에게는 끊은 지 1·3·6개월 뒤 카카오톡이나 문자로 「지금 체중과 식욕은 어떤가요?」를 묻는다" |

> **확인:** 내부 FAQ 「무엇을 만들어야 하고」 → "핵심은 네 가지다 — 조건으로 비슷한 사례 고르기 + 조건 넓히기 · 칸으로 정리한 사례 묶음 · 경험 남기기와 두 가지 동의 · 카카오톡·문자 재질문"

밑줄에서 뺀 문장: 「처방하지 않는다」, 「동의한 것만 보인다」는 해 주는 일이 아니라 지켜야 할 선이라 후보에서 뺐다. 이 선은 시연 ②에서 「빠지면 위험한가」 기준으로 다시 올라온다.

## 시연 ② · 걸러내기

### 후보 7개 → 기능 3개

기준 두 개: **빠지면 헤드라인 약속이 깨지나?** · **빠지면 위험한가?**

헤드라인: 「비만주사를 끊으려는 사람이, 이제 나와 비슷한 사람의 몇 달 뒤를 알고 끊는다」

| 후보 | 판정 | 이유 |
|---|---|---|
| **A · 비슷한 사례 찾기** | ✓ 기능 | 헤드라인 약속 그 자체 (「나와 비슷한 사람의 몇 달 뒤를 알고 끊는다」) |
| **F · 경험 남기기** | ✓ 기능 | 빠지면 약속이 깨짐 — 화면은 동의받은 사례만 보여 주므로, 남기는 사람이 없으면 다음 사람부터 「0명」 화면만 본다 |
| **H · 의학 판단 가드** *(새로 승격)* | ✓ 기능 | 빠지면 위험 — PRFAQ 「가장 아픈 반론」: 사례가 처방으로 읽힌다 |
| B · 시점별 같은 칸 정리 | → A에 흡수 | 기능이 아니라 A의 출력 형식 (「끊은 직후·1·3·6개월 칸으로 나온다」) |
| C · 고비 시점 N건 중 M건 | → A에 흡수 | A의 출력 조건 (「예측 문장 없이 건수로만」) |
| E · 조건 넓히기 | → A에 흡수 | A의 매칭 규칙. 초기엔 사례가 적어 이게 없으면 A가 거의 매번 빈 화면이 된다 |
| G · 1·3·6개월 재질문 | → 다음으로 | 결과가 쌓이는 데 몇 달 걸림. 6주 안에는 1개월 뒤 한 번만 손으로 문자를 보내 첫 관찰만 한다 |
| D · 내 타임라인 겹쳐 보기 | → 다음으로 | 기록이 쌓여야 의미가 있음 — 2단계. 6주 안에는 화면 시안까지만 |

> **기능 3개 = A 비슷한 사례 찾기 · F 경험 남기기 · H 의학 판단 가드** — 3은 미리 정한 숫자가 아니라 통과한 개수다.
>
> \* 「만들지 않을 것」(용량 처방 · 끊을지 말지 판단 · 동의 없는 남의 글 옮기기)은 후보에도 안 올린다 — PRFAQ가 이미 잘랐다.

## 기능별 메모

### A · 비슷한 사례 찾기 (B·C·E 흡수)

- 입력: 약 · 마지막 용량 · 맞은 기간 · 끊는 방식(한 번에 / 간격 늘리기 / 용량 줄이기)
- 출력: 같은 조건 사례를 「끊은 직후 → 1 → 3 → 6개월」 같은 칸으로 나란히 보여 준다 (B)
- 고비 시점은 「이 조건의 기록 N건 중 M건이 끊고 1~2달 뒤 식욕이 확 올랐다」처럼 건수로만 보여 준다 (C)
- 딱 맞는 사례가 없으면 조건을 하나씩 넓히고 무엇을 넓혔는지 적는다 — 예: 「같은 약·같은 방식, 용량만 다름」 (E)
- 그래도 0명이면 「아직 이 조건의 기록이 없어요 — 첫 기록을 남겨 주세요」로 F에 넘긴다

### F · 경험 남기기 (공개 범위 · 동의 포함)

A만 있어도 될 것 같지만, 이 서비스는 찾는 사람과 남기는 사람이 만나는 마켓플레이스 구조라 공급이 빠지면 성립하지 않는다. PRFAQ도 그렇게 말한다.

- 가장 약한 고리 = 「동의받은 사례의 공급」
- 6주 통과 조건 = 「1명 이상 검색 뒤 기록 남김」
- 접는 신호 = 「기록을 남기는 사람이 0명」

체중·투약은 민감정보라, 어떤 칸이 공개되는지 미리 보여 주고 두 가지 동의(닉네임으로 공개 · 1개월 뒤 재연락)를 받는 흐름도 F 안에 넣는다. 이 부분도 빠지면 위험하다.

### H · 의학 판단 가드 — 경고 문구를 기능으로

화면 하단의 「의학적 조언이 아닙니다」 한 줄만으로는 위험이 안 막힌다. PRFAQ의 위험은 사례 화면 자체가 「간격 늘려 끊은 사람이 요요 적었네 → 나도 그렇게」로 읽히는 것이기 때문이다. 그래서 고지문 하나가 아니라 세 층으로 만든다.

| 층 | 언제 | 무엇을 |
|---|---|---|
| ① 상시 고지 | 모든 화면 | 「개인 경험이며 의학적 조언이 아닙니다」 + 「기록을 남긴 사람들의 경험이며 끊은 사람 전체를 대표하지 않습니다」 |
| ② 표현 규칙 | 사례를 보여 줄 때 | 방식끼리 순위·추천 없음, 예측 문장 없음, 「N건 중 M건」으로만 |
| ③ 트리거 경고 *(핵심)* | 용량·재투여·이상 증상이 감지될 때 | 아래 표 |

③ 트리거 경고:

| 감지되는 것 | 동작 |
|---|---|
| 사용자가 용량 질문 (「몇 mg으로 줄여요?」, 「다시 맞을 때 몇 mg부터?」) | 답하지 않고 「용량은 의사가 정해요」 안내로 넘긴다 |
| 남이 남긴 자유 글에 용량 권고 (「5mg으로 줄이세요」) | 그 문장을 가리거나 비공개로 돌린다 |
| 심한 복통·구토 등 이상 증상 서술 | 사례 대신 진료 안내를 먼저 보여 준다 |

- 6주 MVP에서는 AI 없이 키워드 목록(mg, 용량, 다시 맞, 복통 …)으로 시작한다.
- 검증 기준은 PRFAQ의 「좋음」 판정 문장을 그대로 쓴다 — 「화면 어디에도 용량 권고가 나오지 않는가」.
